# WEC Shopify Theme

Independent Shopify Online Store 2.0 theme for Water Equipment Center.

Warehouse-inspired ecommerce UX and merchandising patterns, implemented as an independent theme rather than copying proprietary Warehouse source code.

Current foundation:
- Shopify OS 2.0 JSON templates
- Section groups
- RTL/LTR document direction
- Arabic and English locales
- Sticky header
- Persistent search
- Predictive product search foundation
- Desktop mega-menu foundation
- Product cards
- Quick add foundation
- Product, collection, page and cart templates
- Responsive CSS foundation

Use Shopify CLI locally and run theme check before uploading to a store.
